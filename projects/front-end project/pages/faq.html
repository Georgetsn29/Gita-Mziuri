Frequently Asked Questions

Crafted for the visionaries shaping tomorrow’s web. Here’s what you might be curious about.

Is Aterna suitable for landscape design and gardening businesses?

Absolutely! Aterna is specifically crafted for landscape designers, gardeners, lawn care providers, and outdoor living professionals.

Which Joomla versions are supported by this template?

Aterna supports Joomla 4.x, 5.x, and 6.x versions.

Can I customize the color scheme and fonts?

Yes, it includes 14 preset color styles with full flexibility to create custom schemes via the T4 framework, along with unlimited Google Fonts options.

Is Aterna mobile-friendly and responsive?

Yes, it features a fully responsive design built on the Bootstrap 5 framework to ensure smooth layout display on mobile devices, tablets, and desktops.

Does the template include demo content and layout choices?

Yes, it includes 13 homepage layouts, multiple portfolio pages, and a Quickstart package with full demo content.

What support and updates are included with the template?

Purchasing the template includes 6 months of dedicated author support alongside regular template and plugin updates.
